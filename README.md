# Justin de Haas | Supracom B.V

## Persoonlijke Repo om mijn eigen scripts in kwijt te kunnen. Hier worden scripts in geupdated en hierna verplaatst naar de Supracom Repo wanneer nodig.

### Autopilot
Hier staan scripts in die we kunnen gebruiken om de WDS Server te vervangen zoals het veranderen van het Energiebeheer of het veranderen van de local admin

### Azure AD sync
Kan gebruikt worden bij Entra connect praktijken (Delta sync, Full sync)

### Certificaten Import
Import script voor PFX certificaten (Vecozo, Pien, enz.)

### Check by Cyberdrain.
Check deployment script. Ook de ADMX file is hier te vinden voor Intune.

### Entra Users and Groups
Dit is het script die nu ingezet gaat worden voor nieuwe Microsoft Entra omgevingen. Het originele script dat gebruikt wordt staat in de Supracom Repo

### Intune
Drive mapping ADMX, Policy searcher en een aantal random scripts die ik ooit gevonden heb.

### Overige scripts
Directory voor scripts die niet onder een bepaalde map vallen.

### Sharepoint
Hier worden alle Sharepoint scripts in geplaatst. Hier bevind nu een script om alle deleted sites te verwijderen.

### Windows
Scripts die specifiek bedoeld zijn om op een werkstation te draaien. Dit kan ook vanuit RMM gedaan worden.
